# Snck AI

Snck AI is the Snck-branded deployment entry point for the LibreChat project.

## Ubuntu VPS one-command installer

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/SnckBoy/Ai-Snck/main/install.sh)
```

The installer installs Docker, prepares `/opt/snck-ai`, and starts the application with Docker Compose.

## Project

The application is based on LibreChat. Existing application functionality is intended to remain unchanged; the requested Snck AI branding is applied through configuration/deployment.
